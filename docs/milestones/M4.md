## What works (built)

- **Shared follower** — `plan_ui::following::PlanFollower` (+ `plans_dir`/`active_session`/
  `resolve_plan`) is the one implementation of "which plan does the active thread map to";
  the tab, pill, and panel all use it.
- **Status pill** (`PlanPill`, `StatusItemView`) — `◆ Plan <fragment>` per the state matrix
  (`pill_fragment`: `n/m · acc x/y` when executing, `drafting…`, `approved — launch?`, …);
  follows the active thread; clicking toggles the dock panel. Registered in `zed.rs` behind
  `ZED_PLAN`.
- **Plan panel** (the M0 hello panel, now real) — follows the active thread; header (status
  dot + `Plan · id` + task progress + **sync receipt**); **pipeline column** (task rows with
  status glyphs); **live activity column** from the active thread's tool-call entries.
- **Sync receipts** (F5.3b) — `sync_receipt`: `synced rev N · <last history stamp>`.
