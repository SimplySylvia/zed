## Architecture decision (revised from PRD Part II §1)

The server is **Rust**, not TypeScript: a `plan_server` bin crate using `rmcp` v2.2 over
stdio, depending on `plan_core`, so schema/store/validation have a **single source of
truth** — no re-implementation, no drift. Decided after (a) finding Zed does all its own
agent tooling in Rust and (b) a passing rmcp connectivity spike. Recorded in
`docs/zed-notes.md` and the PRD.

## What works (verified)

- **Seven MCP tools** reusing `plan_core`: `plan_get` (fresh read, never cached),
  `plan_create`, `plan_set_status`, `plan_add_task`, `task_update`, `plan_answer_question`,
  `plan_update_section`. Every mutation bumps `rev` and stamps `history[]` (sync receipts).
- **`planning-mode` skill** — the protocol (questions-first, per-task loop, re-read-before-task,
  enforcement contract).
- **Five hooks** as `plan_server hook <event>` subcommands: SessionStart/UserPromptSubmit/
  PreCompact inject the active plan; **PreToolUse denies file edits unless a plan is
  executing**; Stop is a placeholder loop guard.
- **Wiring**: `plan-agent/settings-fragment.json` + `plan-agent/README.md`.

## Dogfood (T8) — the point of M2

Ran the full loop in an isolated scratch project (`/tmp/plan-dogfood`) with the real server
+ hooks + skill wired into plain Claude Code (headless):
- **3 clean draft → launch → execute cycles** (DOG-1/2/3), each ending `t1 done`, rev 4,
  3 history entries. **Zero skill tuning required** — the §7 "3× clean" adherence bar met.
- **Enforcement observed in context:** with a plan in `drafting`, Claude Code's attempt to
  `Write` code was **blocked by the PreToolUse hook** (file never created); after launch to
  `executing`, the same edit was allowed.
- **Skill adherence:** the agent re-read via `plan_get` before executing, recorded evidence
  via `task_update`, and even flagged that it should run tests + commit per the per-task loop
  (those steps need `Bash` allowed — not granted in the scoped dogfood).
- **Sync receipts:** every tool write bumped `rev` and appended `history[]`, exactly as the
  UI will render.

The §7 risks this milestone targeted — "hooks can't deny/inject" and "agent forgets the
protocol" — did **not** materialize.
